私隱聲明

本 App 點處理你嘅資料

1. 我哋收集咩

  • 你輸入嘅姓名同稱呼（可選，唔輸入亦可匿名使用）
  • 你嘅測試結果（4 字母類型）、版本、時間
  • 本機最近 5 次測試紀錄

2. 我哋點儲存

所有資料只儲存喺你部機嘅瀏覽器（localStorage），由系統管理。

  • 開發者 無法存取你嘅資料
  • 資料 唔會上載到任何伺服器
  • 清除瀏覽器資料 = 永久刪除所有紀錄

3. 我哋點分享

唔會將測試紀錄分享畀第三方。

4. 你嘅權利

  • 逐筆刪除：喺「我的記錄」頁，每筆都有刪除掣
  • 全部清除：同一頁「紀錄管理」或頂欄 ⋯
  • 永久刪除：喺瀏覽器設定清除網站資料

5. 聯絡

如對私隱有任何查詢，可透過 GitHub Issues 聯絡開發者：
github.com/fung2222/hk-mbti/issues
