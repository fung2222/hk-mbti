## 六個真 bug（全部有用戶症狀）

1. **人格頁「場景」分頁 10 個場景掣全部撳唔到** 🔴（silent fail）
   根因：`openSocialArticle(key, type)` 要 **2 個**參數，但 `renderTypeTabs()` 嘅 `mk()` 生成 onclick 時**只傳 key**
   → `articles[undefined]` = undefined → `if(!article || !T) return;` **靜靜咁 return**（冇 error、冇反應）。
   點解一直捉唔到：個 onclick 係**字串拼接**出嚟（靜態 grep 睇唔到）＋舊測試只驗「onclick 字串有冇函數名」＝**假守門**。
   修：補 `type` 參數；測試改成「驗參數數目 ＋ **真撳** ＋ 驗文章內容真係 render」。
2. **16 型卡入完再返百科，16 張卡全部變半透明** 🔴（Roy 截圖報告）
   根因：`.hub-type-grid.is-picking .hub-type-card{opacity:.6}`（兩段式選中態）；`openType()` 離開時只清主頁跑馬燈，
   冇清 `#hubTypeGrid`；而 `#hubTypeGrid` **只開機 render 一次** → 一掛 `is-picking` 成個 session 都淡。
   修：集中式 `clearTypePick()`，`openType()` ＋ **`show()`（任何頁面切換）**都叫。
3. **返回鍵唔會還原捲動位置**（全站）
   根因：`show()` 先捲返頂才寫 history → 記錄嘅 `sy` 永遠 0。修：改成「離開嗰刻」捕捉。
4. **`#deepChapter` 章節返回會跳去目錄**（唔係上一頁）
   根因：`openDeepChapterFromType()` 先叫 `openDeepType()` → `show("deep")` 造 **+3 層 phantom history**。修：只設狀態（+1 層）。
   同時加：導覽堆疊 persist 落 `sessionStorage`（reload 後仍可返「上一頁＋位置」）。
5. **4 個 sub-page 選單仲有 3 個已淘汰連結**（指向已刪嘅光譜／相處／拍拖）
6. **preflight 嘅 emoji 檢查形同虛設** —— 我自己喺 `4809518` 加咗 **5 個 `⚠️` 註解**（違反「全站冇 emoji」鐵律，
   歷來第 4 次：`5373a96`／`4f03b11`／`4849d73`／`4809518`，**全部都係註解**）。
   點解走漏 4 次：檢查一直只入 `warns` → 帶住 emoji 都照印「全部通過」＋ exit 0。
   修：清 emoji ＋ **升級做硬失敗**（真攔測試過：暫插 emoji → exit 1；還原 → exit 0）。

## 技術發現（已寫入 skill）

1. **假守門**：只驗「字串」唔驗「行為」 —— 舊斷言 `/open(Social|Romance)Article\(/.test(onclick)` 令死掣照綠。
   → **有 onclick／按鈕嘅測試，一定要真 dispatch click 再驗結果狀態有變**。
2. **錄影式 2D context（新手法）**：jsdom 冇 canvas pixel → 覆寫 `HTMLCanvasElement.prototype.getContext`，
   記錄 `generateCardImage()` 真正落嘅每個 `fillText`／`drawImage`／`fillRect` 座標（`textAlign` 要自己換算 left／right、
   `measureText` 用 CJK 1em／拉丁 0.58em 估闊、`w.Image` 要 stub）→ 可以實量度「有冇重疊／出界」。
   **呢個係睇 canvas 版面嘅唯一方法**（我睇唔到 render）。
3. **拼接式 onclick 係盲區**：`'...onclick="' + fn + "('" + k + "')"` 靜態 grep 睇唔到參數對唔對 → 要真跑 DOM。
4. **`preflight` 唔可以只睇尾行**（`tail -1` 會睇漏警告）→ 要 `grep '⚠'` ／睇「N 項有問題」。
5. **`#hubTypeGrid` 只開機 render 一次** → 任何頁內 class 狀態必須離開時清，否則成個 session 殘留。
6. **導覽堆疊要 persist 落 `sessionStorage`** → reload 後仍可返「上一頁＋位置」。
7. **`.trait-bar` 係死 CSS**（更早期版本嘅屬性棒棒圖殘骸，冇使用點）；
   而「性格刻度」3 條屬性棒（企硬力／社交力／食力）**一直都在**人格頁「性格」分頁 → 唔存在「被取消」。
