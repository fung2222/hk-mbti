### D. 離線彈窗問題（今日最難，用業界標準解決）
**症狀**：飛行模式下，任何頁（除「我的紀錄」）下拉更新／跳頁 → 出一個空白對話框（只有「取消／確定」）、撳唔到、只可強制關 app；重裝 app／無痕模式都一樣。
**根因（Grok 4.7 ＋ DeepSeek v4 Pro 兩份獨立審計一致）**：
1. `#appDialog` 嘅 HTML 預設狀態被 CSS 露出（`.ad-overlay{display:flex}` 喺頁面自己 `<style>`，但 `.hidden{display:none}` 只喺 `tailwind.css`）
2. **`tailwind.css` cache miss**（`install` 用 `Promise.allSettled` 吞失敗又冇重試）→ 頁面排版散，隱藏元素全部走出嚟
3. **「我的紀錄」冇事**：`record.html` 幾乎唔靠 tailwind（只用 1 個 utility class／38 個；index.html 用 32 個 `.hidden`／1843 個）→ 完全解釋到個矛盾
4. **收到修復但仍然壞**：`sw.js` 用 `c.add()` 會食 GitHub Pages 嘅 `cache-control: max-age=600`；cache 名冇變 → `activate` 唔會清同名 cache 嘅舊 HTML；`/hk-mbti/` 同 `/hk-mbti/index.html` 係兩條 key
5. `cache-first` 分支 `return cached || fetchPromise` 離線 cache miss 時回 `undefined` → `respondWith(undefined)` throw

**修法（全部係業界標準做法）**：
- `sw.js`：`c.add()` → `fetch(u, {cache:"reload"}) ＋ put`；HTML 導航加 `cache:"reload"`；cache 失效試齊兩條 key；**`activate` 改為全量 cache 重置**（刪走所有 cache ＋ 由網絡重抓齊）；封死 `respondWith(undefined)`
- 每頁自帶 `.hidden{display:none}`（唔再靠外部 CSS）
- `#appDialog` inline `display:none` ＋ 掣改成「載入時一次綁定」（冇 `_resolved` 都關得）
- **自癒哨兵**：偵測 `tailwind.css` 冇生效 ＋ 有網絡 → 清壞 cache ＋ 更新 SW ＋ reload 一次（用戶零操作）
- **Roy 確認：已解決** ✓（可以無限下拉更新 ✓）
